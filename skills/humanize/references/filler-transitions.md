## Reduce Formal Transitions

AI overuses signpost transitions that make prose feel stiff and over-structured.

**AI pattern:**
> Moreover, it’s important to note that the new API reduces latency. That being said, there are trade-offs.

**Human alternative:**
> The new API reduces latency, but there are trade-offs.

**Words to watch:** furthermore, moreover, additionally, it’s important to note that, it’s worth noting, it’s worth mentioning, that being said, with this in mind, firstly/secondly/thirdly/lastly

**Fix:** Remove the signpost. If you need a transition, use a simple one (often: “also”, “but”, “so”).
