## Avoid Synonym Cycling

AI has repetition-penalty code causing excessive synonym substitution for the same concept.

**AI pattern:**
> The protagonist faces many challenges. The main character must overcome obstacles. The central figure eventually triumphs. The hero returns home.

**Human alternative:**
> The protagonist faces many challenges but eventually triumphs and returns home.

**Pattern to watch:** If you're referring to the same thing, use the same word. Elegant variation is a tell.

**Fix:** Pick one good word and move on. If you need emphasis, add a concrete detail instead.
