## Use Straight Quotes

ChatGPT uses curly quotes ("...") instead of straight quotes ("...").

**AI pattern:**
> He said "the project is on track" but others disagreed.

**Human alternative:**
> He said "the project is on track" but others disagreed.

**Fix:** Replace curly quotes with straight quotes for consistency, especially in code contexts.
